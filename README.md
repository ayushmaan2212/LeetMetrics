# 🚀 LeetMetrics

LeetMetrics is a simple web dashboard that displays LeetCode user statistics in a visual and easy-to-read format.

Enter a LeetCode username to view solved problem counts for Easy, Medium, and Hard difficulty levels with animated progress circles.

---

## ✨ Features

✔ Fetches LeetCode user stats  
✔ Animated progress rings  
✔ Clean and minimal UI  
✔ Username validation  
✔ Responsive layout  

---

## 🛠 Tech Stack

- HTML  
- CSS  
- Vanilla JavaScript  
- Community LeetCode Stats API  

---

## 📊 Stats Displayed

- Easy problems solved  
- Medium problems solved  
- Hard problems solved  
- Visual progress indicators  

---

## 🚀 How to Run

1. Clone the repository

```bash
git clone https://github.com/ayushmaan2212/LeetMetrics.git
```

2. Open the project folder

3. Open `index.html` in your browser
